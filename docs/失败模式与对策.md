# NestKB 失败模式与对策

> 对照《调研二：AI-Agent 与大模型项目实践调研》§3.2 归纳的 RAG 生产六类高频失败，逐条标注本项目的防御手段与残留风险（调研二共同设计原则第 2 条：每个项目写一页"失败模式与对策"）。

| # | 失败模式 | 本项目的防御（代码位置） | 状态 | 残留风险与对策 |
|---|---|---|---|---|
| 1 | **知识陈旧 / 文档漂移**：旧版本文档继续被引用，回答基于过期制度 | `document_versions.expires_at` 时效元数据：检索层 `expires_at > now()` 过滤（不可召回）；`replaceVersion` 先删后写单事务防新旧版本混检；版本替换后旧版本 chunk 清除；引用携带 `effectiveAt/versionNo`；`POST /admin/documents/:id/expire` 手动标记过期 | 部分防御 | 过期后是"消失"而非"降权提示"（计划书 P1 的降权灰度未做）；需要"过期内容仍可引用但带提示"时改 `searchVectors` 为降权排序。文档漂移的主动探测（定期 checksum 重扫）未实现 |
| 2 | **检索精度在规模下退化**：单路向量召回不足、排序漂移 | 混合检索双路召回（pgvector HNSW + FTS tsvector + pg_trgm 兜底）→ RRF 融合（只比排名 k=60）→ rerank top-50→8；`/admin/retrieval/debug` 暴露双路原始分数/RRF 排名/rerank 前后/分段延迟；`query_logs.latency_breakdown` 分层归因（难点 8 的排查顺序） | 已防御 | 规模超百万 chunk 需迁 Qdrant（VectorStore 已接口化）；中文 FTS 依赖 simple 配置 + trgm，中文分词最优解需 zhparser（自编译） |
| 3 | **表格检索失效**：表格被拦腰切碎，数字答非所问 | `libs/chunker/groupTableBlocks`：连续 `\|` 行聚合为整块，**表格再大也不切**（单测覆盖）；DOCX 解析转 markdown 管道行保留表格结构 | 已防御（MD/DOCX） | PDF 内表格解析为纯文本行，表格结构丢失（pdf-parse 不还原表格）；需要时接表格识别（P2-14 的 OCR/结构化方向） |
| 4 | **权限泄漏**：越权文档内容进入回答 | **检索层强制主体过滤**：`accessWhereSql` 是每条检索 SQL 的第一个 WHERE（company/department/whitelist-EXISTS 三分支，default deny）；`AccessScope` 为检索接口必选参数（无权限主体无法构造检索）；E2E 越权矩阵断言 citations 与 retrieval_snapshot 均不含越权 chunk；白名单支持部门/个人/带过期授权 | 已防御 | 新增访问级别必须补跨部门 E2E 用例（T01）；权限过滤遗漏的最后一道防线是引用可点开人工核验（chunkId+versionNo） |
| 5 | **缺溯源 / 幻觉引用**：模型编造 `[5]` 而上下文只有 4 块 | `validateCitations` 后处理：越界/重复编号剔除并告警（幻觉引用监控指标 dropped/total）；citations 携带 `chunkId+documentId+versionNo+quote(200字)+headingPath+effectiveAt`，前端可反查比对；prompt 层强制"编号只能取自资料编号" | 已防御 | 编号对了但内容引用错位仍依赖 LLM；引用剔除率周趋势监控（eval_runs 留档）是发现模型漂移的信号 |
| 6 | **成本归因不清**：token 花费无法对账到部门/场景 | usage_records 以 API 返回 usage 为唯一计费依据，场景分账（qa/ingest_embed/rerank/eval/summary）+ requestId 贯穿；摄取 embedding 花费同步落库（scene=ingest_embed）；三道闸：预扣护栏（Redis NX+TTL）→ 部门月配额（耗尽降级只读 + 看板告警）→ 部分结算回冲（中断不漂移）；成本看板按部门/用户/天/场景聚合 + P95 | 已防御 | cached_tokens 折扣系数（0.5）是假设值，接真实 provider 后按账单校准；语义缓存关闭状态，FAQ 负载大时可保守开启 |

## 附加防御（超出 §3.2 六类之外）

| 风险 | 防御 |
|---|---|
| **间接注入**（文档内嵌"忽略以上指令"） | 文档内容视为不可信输入：`libs/prompts/guard` 上传/检索双侧扫描告警；用户输入硬闸（索要系统提示直接拒绝，E2E T13 覆盖）；分层 prompt（系统指令与资料定界符分离）。规则为保守启发式，误报只告警不阻断 |
| **毒文档无限重试烧钱** | ParseError 分类（ENCRYPTED_PDF/DOCX_CORRUPTED/EMPTY…）→ `UnrecoverableError` 直进 DLQ，不烧 embedding 配额；DLQ 人工重放（`POST /documents/:id/reingest`） |
| **评估集过拟合** | 评测集独立版本化且迭代期不许改；三来源（人工/点踩回流/失败专项）；eval_runs 五元组留档，"回归分数涨、点踩率涨"即冻结 prompt |
| **rerank 依赖** | rerank 是增强不是依赖：超时 800ms 降级 RRF 序 + `x-rerank-degraded` 标记 + query_logs 留痕（E2E 验证降级链路） |
| **停机丢任务** | SIGTERM → BullMQ 等当前 job 完成 → 连接关闭；stage 状态落库可断点观测 |
